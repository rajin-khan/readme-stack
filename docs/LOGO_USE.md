# Logo use and attribution

README Stack combines its own code with names and marks owned by other people and organizations. A generated stack identifies the tools you selected. It does not say that those companies sponsor, endorse, or work with you or README Stack.

## When you embed a generated stack

Keep the generated image intact and use it to describe a real toolset. Do not use a stack as a company logo, app icon, certification badge, or advertisement. Do not alter a mark in a way that could suggest a partnership or endorsement.

README Stack keeps source, license, and policy links in its [third-party notices](../THIRD_PARTY_NOTICES.md) and generated [catalog metadata](../public/catalog.json). Some owners require additional attribution or restrict commercial and promotional use. Check the linked source and brand policy if your use goes beyond a personal README or project documentation.

The Simple Icons package uses CC0, but its disclaimer notes that CC0 does not clear every trademark or every icon-specific right. README Stack preserves the icon-specific license when Simple Icons lists one. If no icon-specific license is listed, the catalog records the pinned package and original source without claiming that the mark is unrestricted. Devicon uses the MIT License and likewise says that product names and marks remain with their owners. An icon package entry is a source record, not permission from the brand owner.

README Stack replaces artwork carrying noncommercial, share-alike, GPL, or AGPL terms with a neutral glyph when embedding the original mark could pass unclear obligations to generated SVGs. The Tool name remains for identification.

## When you copy or modify an asset

The generated SVG endpoint is the supported way to use the catalog. If you extract, recolor, modify, redistribute, or use an individual asset elsewhere, review that Tool's `source`, `rights.license`, and `rights.notice` fields in [`public/catalog.json`](../public/catalog.json). You are responsible for following the applicable license and brand rules for that separate use.

## Corrections and removal

Brand owners can request a source correction, artwork change, or removal through the [Tool request and catalog issue form](https://github.com/rajin-khan/readme-stack/issues/new/choose). Maintainers give those requests priority.

This page explains how README Stack records and presents third-party marks. It is not legal advice.
