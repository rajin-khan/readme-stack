About

An animated tech stack generator for GitHub profiles

README Stack turns a hand-picked set of developer tools into one self-contained SVG. Add the image to a GitHub profile README, project README, portfolio, or documentation page.

Choose 2 to 24 tools from a catalog built with Simple Icons and Devicon. Control the background, speed, direction, spacing, names, motion, and Tool size, then copy Markdown or theme-aware HTML.
